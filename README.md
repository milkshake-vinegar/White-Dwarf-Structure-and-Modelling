This repository contains methods to generate Mass-Radius relations and compute the structure for white dwarfs, stellar remnants that form after the death of low-mass and Sun-like stars. 

The main report of this investigation with the code and plots are contained in this repository.
It consists of utilising numerical integrators to solve the newtonian hydrostatic equilibrium equation and the TOV equation using a zero-temperature degenerate electron gas as the equation of state. Other effects such as coloumb interactions between ions, finite-temperature and nuclear interactions are considered in plotting the mass-relation curves which can unconver phenomenae such as the Chandrasekhar limit.  

Finally, we can compute properties of the white dwarf's structure such as pressure, mass, density etc at a certain radial depth with closer inspection in how various interactions can affect these variables at different depths.
